# bsa — Bedside Monitor Sound Simulator

ベッドサイドモニターの音（心電図同期音・アラーム音）と波形を再現するブラウザアプリ。学習・デモ用で、医療用途には使えません。

## 使い方
`index.html` をブラウザで開いて「開始」を押す（Web Audio は操作後でないと鳴らないため）。

音はすべて次の動画の録音を解析した値から合成している。

1. 日本光電 LifeScope TS デモアラーム https://www.youtube.com/watch?v=VL5GPBYp9R4
2. 日本光電 BSM-2301 紹介（SOUND CHECK 画面）https://www.youtube.com/watch?v=KpVvuiz1LaQ
3. 日本光電 心電図モニター音源 https://www.youtube.com/watch?v=IKfJOQkzVNU

### 同期音
1 拍ごとの音程は一定。「SpO2 で音程を変える」にチェックを入れると、SpO2 1% につき半音変わる（動画2 で半音刻みの変化を確認）。

| 種類 | 音 |
|---|---|
| LifeScope TS（動画1） | 940Hz の純音、約 70ms |
| 日本光電 標準（動画3） | 784Hz、3 倍音が強いやわらかい矩形波。150ms 保持して減衰、計約 0.28s |
| BSM-2301（動画2） | 894Hz の矩形波、約 70ms |

### アラーム音
音タイプ NK1 / NK2 / BSM-2301 / IEC を選べる。

| | クライシス（赤） | ワーニング（黄） | アドバイザリ（水色） |
|---|---|---|---|
| NK1 | 1147Hz と 939Hz を 57.5ms 周期で交互に鳴らすトリル 0.37s、1s 周期 | 917Hz 0.26s → -7dB の余韻、1s 周期 | 727Hz 減衰音（推定） |
| NK2 | 1272Hz チャイム（2 倍音 -7dB）、0.72s 周期 | 870Hz を 2 回打鍵「ポ・ポーン」、2 打目は -6.5dB で保持、1.96s 周期 | 727Hz 減衰音（推定） |
| BSM-2301 | 1091Hz を 60ms ごとに打ち直す「ビビビ」0.55s、1.02s 周期 | 881Hz → 700Hz「ピポー」、1.06s 周期 | 700Hz 0.7s |
| IEC | ド・ミ・ソ―ソ・ド ×2、約 9.6s 周期 | ド・ミ・ソ、約 9.9s 周期 | ミ・ド |

アドバイザリの繰り返し間隔は 20s / 120s から選べる。

### その他
- **デモアラーム**: 正常 → 頻脈 → SpO2 低下 → 徐脈 → 電極外れ → VT → VF → 心静止 を 12 秒ずつ自動で切り替える
- 消音（2 分。新しいアラームが出たら解除）、上下限の設定、NIBP 測定
